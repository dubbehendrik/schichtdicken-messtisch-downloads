# Roboterschichtdicken Messtisch – Downloads

[**Aktuellen Windows-Installer herunterladen**](https://github.com/dubbehendrik/schichtdicken-messtisch-downloads/releases/latest)

Auf der Release-Seite unter **Assets** die Datei **Roboterschichtdicken-Messtisch-Setup.exe** wählen. Download und Updateprüfung funktionieren ohne GitHub-Konto.

## Installation
- Windows 10/11, 64 Bit; Bluetooth für MEGA-CHECK DX und USB/COM für DOBOT Magician.
- Installation pro Windows-Nutzer; Python muss nicht separat installiert werden.
- Zunächst die Simulation prüfen. Der erste reale Mehrpunktablauf muss am Laboraufbau geprüft werden.
- Der Installer ist derzeit nicht mit einem Windows-Code-Signing-Zertifikat signiert.

## Updates
Ab Version 0.1.1 prüft **Nach Updates suchen** dieses öffentliche Repository. Herunterladen und Installieren erfolgt erst nach ausdrücklicher Zustimmung. Vorher werden lokale Programmdaten gesichert; SHA256 und Dateigröße werden geprüft. Während Messung und Einlernen sind Updates gesperrt.
Version 0.1.0 benötigt einmalig den neuen Installer von dieser Seite, da die alte Updateadresse noch auf das private Repository verweist.

Programme und Messungen liegen außerhalb des Installationsordners und bleiben beim Update erhalten. Die Anwendung verarbeitet Messdaten lokal.

## Inhalt dieses Repositorys
Hier liegen ausschließlich Downloadhinweise, Installer und Prüfsummen. Der Entwicklungsquellcode bleibt im privaten Repository. Die automatisch angebotenen „Source code“-Archive enthalten nur den Dokumentationsstand dieses Download-Repositorys.

Neue Installer werden im privaten Entwicklungsrepository unter Windows gebaut und geprüft und anschließend als Release-Assets hier veröffentlicht. Bestehende Versionsdateien werden nicht überschrieben.
